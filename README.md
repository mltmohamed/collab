# Collab

Projet collaboratif — en cours de démarrage.

## Démarrage

```bash
git clone https://github.com/mltmohamed/collab.git
cd collab
npm install
npm run dev
```

Autres commandes :

- `npm run build` — build de production (dans `dist/`)
- `npm run preview` — prévisualiser le build
- `npm run lint` — vérifier le code

Stack : React 19 + Vite.

## Contribuer

1. Créer une branche : `git checkout -b ma-fonctionnalite`
2. Commiter ses changements : `git commit -m "Ajout de ..."`
3. Pousser la branche : `git push origin ma-fonctionnalite`
4. Ouvrir une Pull Request
